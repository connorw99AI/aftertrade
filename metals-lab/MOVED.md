# Metal Lab has moved

Metal Lab now lives in its own repository: https://github.com/connorw99AI/Metal-Trading-Lab

On your PC:

1. `git clone https://github.com/connorw99AI/Metal-Trading-Lab.git`, then run `scripts\windows\setup.ps1` inside it.
2. Copy `config\config.yaml` and the `data\cache\` folder from this old folder into the new one (Metal Lab stopped).
3. Start Metal Lab from the new folder from now on. This folder no longer receives updates.
